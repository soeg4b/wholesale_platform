- **Read (actual source)**: `apps/api/src/**` (all modules), `apps/api/prisma/{schema.prisma,sql/*.sql,seed*.ts,apply-*.ts}`, `apps/web/{app,components,lib}/**`, `next.config.mjs`, root + app `package.json`, `.env.example`, `docker-compose.yml`, `scripts/*`, artifacts 06/07/08. - **Not done**: no build, tests or `npm audit` were run (no execution available). All fixes below are unbuilt and untested; run build + `npm test` + `scripts/smoke.mjs` before release.
- **Threat surfaces**: unauthenticated (auth, webhooks, public stats), buyer, operator (tenant isolation, KML upload, API-config SSRF, free text), admin, LLM prompts, build/runtime config.
- **Convention check (404 vs 403)**: tickets, reservations, api-configs, add-ons, geo, insights, performance return 404 for out-of-scope objects and 403 only for in-scope-but-not-allowed actions. Consistent, no existence oracle found.

## 7. Production hardening checklist
- [ ] `NODE_ENV=production`; random `JWT_ACCESS_SECRET` and `CREDENTIALS_ENCRYPTION_KEY` (>= 32 chars) from a secret manager; never set the `ALLOW_*`/`ENABLE_MOCK_OPERATOR` demo flags; `ALLOW_PRIVATE_OPERATOR_URLS` unset (it is `true` in the dev `apps/api/.env`).
- [ ] Set `payment.provider=midtrans`, `demo.incidentInjection=false`, `demo.countInMetrics=false`; do not run the demo seed; delete `*@demo.wnmp.test` users if present.
- [ ] TLS at the proxy, `TRUST_PROXY_HOPS`, edge rate limiting (including webhooks), request logging and alerting (S-23).
- [ ] DB: separate migration/owner role from runtime role (no DDL, no trigger changes), non-default password, no public port, backups, ledger head-hash anchoring.
- [ ] Egress firewall for the API (block RFC1918, link-local, metadata) as the real SSRF control.
- [ ] Web: CSP with nonces, move JWT to httpOnly cookie, upgrade Next to a supported line, `npm audit` in CI.
- [ ] Convert all `@Body()` interfaces to class DTOs (S-10), add refresh/revocation (S-12), scope reservation payloads (S-16).
